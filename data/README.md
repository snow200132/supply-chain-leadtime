# Data Architecture & Source Link

* **Master Source Dataset:** [Kaggle - DataCo Supply Chain Dataset](https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data)
* **Scale:** 180,519 total transaction records filtered across 3 regional fulfillment hubs (Lagos, Kano, Port Harcourt).
* **Storage Note:** Due to GitHub file size constraints, raw data is hosted externally on Kaggle. Schema representation is available locally in `sample_schema_preview.csv`.
